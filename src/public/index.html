🏛️ The Four Pillars of the Vault
Pillar 1

The Blueprint (Schema & Relational Geometry)

Enforces Primary Keys, Foreign Keys, 1:1 (Users ↔ Profiles), 1:Many (Users → Items/Folders, Customers → Orders), and M:M (Items ↔ Tags, Students ↔ Courses).

Pillar 2

The Bridge (Integration & Connection)

Native prepared SQLite engine with Write-Ahead Logging (WAL), connection pooling, and transactional safety.

Pillar 3

The Action (CRUD & RESTful HTTP)

Complete HTTP verbs (POST, GET, PUT, PATCH, DELETE) mapped to SQL statements with semantic HTTP status envelopes (200, 201, 400, 404, 409, 422).

Pillar 4

The Shield (Integrity & Security)

Schema-level UNIQUE, NOT NULL, CHECK constraints, and 100% Parameterized Queries neutralizing SQL Injection attacks.

🔗 1:1 Relationship (One-to-One)
users.id (PK) ⟷ user_profiles.user_id (FK, UNIQUE)

A strictly exclusive relationship enforced via the UNIQUE constraint on user_profiles.user_id. Each user record has exactly one security clearance profile.

CREATE TABLE user_profiles ( id INTEGER PRIMARY KEY AUTOINCREMENT, user_id INTEGER NOT NULL UNIQUE, full_name TEXT NOT NULL, clearance_level INTEGER NOT NULL CHECK(clearance_level BETWEEN 1 AND 5), FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE );
📂 1:Many Relationship (One-to-Many)
users.id (PK) ⟶ vault_items.user_id (FK)
customers.id (PK) ⟶ orders.customer_id (FK)

A single parent entity connecting to multiple child entities. Deleting a parent automatically cascades to child items or sets references to null.

CREATE TABLE vault_items ( id INTEGER PRIMARY KEY AUTOINCREMENT, user_id INTEGER NOT NULL, folder_id INTEGER, title TEXT NOT NULL, FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE, FOREIGN KEY (folder_id) REFERENCES vault_folders(id) ON DELETE SET NULL );
🏷️ Many-to-Many (M:M Junction Table)
vault_items ⟷ vault_item_tags ⟷ tags
students ⟷ student_courses ⟷ courses

Multiple Vault Items connected to multiple Tags using a dedicated intermediary junction table with a composite primary key.

CREATE TABLE vault_item_tags ( vault_item_id INTEGER NOT NULL, tag_id INTEGER NOT NULL, assigned_at DATETIME NOT NULL DEFAULT (datetime('now')), PRIMARY KEY (vault_item_id, tag_id), FOREIGN KEY (vault_item_id) REFERENCES vault_items(id) ON DELETE CASCADE, FOREIGN KEY (tag_id) REFERENCES tags(id) ON DELETE CASCADE );
